About Vintage Photo Prompt

Vintage Photo Prompt is a small, free library of 1980s photo prompts for AI image tools, run by Vivian Wang. This page explains where the prompts come from and what was done to check them, so you can judge how much to trust each one.

Prompts for your own photo

The 46 prompts in the ChatGPT 1980s photo prompts collection were written for this site. Each one was run on a fictional, AI-generated reference portrait, and 46 of them show that real result next to the “before” photo on their page. No real person's photo was used.

Text-to-image examples

The text-to-image gallery shows 18 prompts shared publicly by their creators on OpenArt, credited and linked on each page. Out of a larger set, only the ones whose example image genuinely reads as a 1980s photograph were kept; the rest were removed from the site.

Updates and corrections

Each prompt page shows the date its text last changed. See the image license for how you may reuse the example pictures.
